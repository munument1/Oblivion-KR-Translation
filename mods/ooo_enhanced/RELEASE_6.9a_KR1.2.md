# OOO Enhanced 6.9a 한국어 패치 KR1.2

GitHub #24·#25의 후속 교정입니다. OOO Enhanced가 덮어쓰는 무기·퀘스트·장소 표기에서 본편 v1.2.3과 용어를 맞췄습니다.

원작은 Saldron의 [OOO Enhanced](https://www.nexusmods.com/oblivion/mods/47187)입니다. 원본 6.9a의 폴더 구조를 따른 교체 ESP 24개를 포함합니다. 원본 및 리소스, OOO 본체, obCJK UTF-8 환경이 필요합니다.

전체 ESP의 구조를 검증했습니다. 변경된 본편 ESP를 xEdit으로 다시 대조했고, 선택 ESP 23개는 KR1.1과 해시가 일치합니다. 생성형 AI를 번역 교정에 사용했습니다. 실게임 플레이 검증은 생략했습니다.
