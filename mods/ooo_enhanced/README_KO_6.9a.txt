OOO Enhanced 6.9a 한국어 패치 — 6.9a-KR1.0 (2026-11-10)

원본 OOO Enhanced 6.9a와 필수 모드를 먼저 설치하세요.
원본 다운로드 폴더 이름은 6.9로 표시되지만 본편 ESP의 내부 버전은 6.9a입니다.
이 ZIP은 본편과 선택 ESP 24개의 UTF-8 번역 교체 파일입니다.
메시·텍스처·BSA, OOO 본체 ESM/ESP는 포함하지 않습니다.
기존 OOO 본체 한국어판과 obCJK UTF-8 환경·한글 글꼴이 필요합니다.

설치
1. 6.9a 원본 압축을 별도 폴더에 풉니다.
2. 이 번역 ZIP을 같은 폴더에 풀어 동일 경로의 파일을 덮어씁니다.
3. 합쳐진 폴더를 다시 압축해 MO2에서 원본과 같은 방식으로 설치합니다.
4. 선택 패치는 기존에 사용하던 구성만 선택합니다.
   Easy Difficulty와 Hard Difficulty는 함께 활성화하지 마세요.
5. Bashed Patch를 사용한다면 번역 적용 후 다시 생성합니다.

변경
발렌우드 순찰자와 노예상인·밀수꾼 관련 일지 148개 추가·변경 항목을 반영했습니다.
기존 번역 자료를 원문과 대조 검토하고 인명·야영지·동굴 이름을 정리했습니다.
메인 퀘스트의 관문 알림은 원본 변경에 맞춰 '두 번째'로 반영했습니다.
전체 한영 대조표 15,970행과 변경 대조표 150행을 GitHub에 보관합니다.
선택 ESP 23개는 이전 6.9-KR1.0과 바이트 단위로 같습니다.

검증
24개 ESP, 76,829개 레코드와 1,422개 스크립트 구간의 정적 검사를 통과했습니다.
TES4Edit 4.1.6r9에서 영문 6.9a와 한국어판을 동일한 마스터·로드 순서로 비교했습니다.
선택 ESP 23개는 진단 없음. 본편의 비영속 참조 진단 6건은 원본과 한국어판이 같습니다.
번역으로 추가된 xEdit 진단은 0건입니다. 원본의 게임플레이 수정 사항을 그대로 유지했습니다.
실제 게임 실행은 미검증입니다.
