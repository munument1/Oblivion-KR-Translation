# OOO Enhanced 6.9a 한국어 패치 KR1.1

GitHub #24·#25에서 보고된 표기와 퀘스트 일지의 한국어 문구 6곳을 교정했습니다. 원작은 Saldron의 [OOO Enhanced](https://www.nexusmods.com/oblivion/mods/47187)입니다. 기존 6.9a 한국어판의 출처와 기여자 안내는 ZIP에 동봉했습니다.

원본 6.9a의 폴더 구조를 따른 교체 ESP 24개를 포함합니다. 원본 모드와 리소스, OOO 본체, obCJK UTF-8 환경을 설치한 뒤 사용하던 선택 패치만 적용하세요.

전체 ESP의 구조를 검증했습니다. 변경된 본편 ESP는 xEdit으로 다시 확인했고, 원본과 번역판에 같은 진단 6건이 나왔습니다. 선택 ESP 23개는 이전 검증본과 해시가 일치합니다. 생성형 AI를 사용해 번역을 교정했으며 실게임 플레이 검증은 생략했습니다.
