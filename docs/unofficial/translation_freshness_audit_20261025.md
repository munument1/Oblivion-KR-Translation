# 비공식 패치 번역 최신화 조사 — 2026-10-25

현재 공개된 v1.1.7의 UOP KR1.10 / USIP KR1.7 / UODP KR1.9 ESP 13개와 최신 본편·공식 DLC 번역을 대조했다. 기존 공개 패키지의 SHA256을 고정하고, master 소유권·레코드 종류·FormID·EditorID·필드 순번과 양쪽 영문 원문 해시를 확인했다.

## 발견

표시 필드 10,540개를 확인했다. 본편과 비교 가능한 영어 변경 예외 중 한국어가 달랐던 473개를 검토했다. 원문이 오타·문법 수준으로 달라졌어도 `patch` 정책이 한국어 문장 전체를 이전 번역으로 보존하고 있었다. 따라서 초기 번역이 남았다는 의심은 서적뿐 아니라 대사와 일지에서도 확인됐다. 473개 모두가 오류라는 뜻은 아니다.

- UOP INFO 0001DC28 / NAM1 / occurrence 3: 영어 `that → who` 변경 때문에 ‘나는 니가…’, ‘도와 줄꺼지?’가 남아 최신 본편 문장이 적용되지 않았다.
- UOP INFO 00047688: 패치 원문은 Light Armor 훈련인데 기존 번역은 잠금해제 훈련이었다. 최신 문장을 바탕으로 경갑으로 수정했다.
- UOP INFO 00035672 / NAM1 / occurrence 4: 패치 원문은 광산이 길 북쪽이라고 고쳤지만 번역은 남쪽으로 남았다. 북쪽으로 수정했다.
- UOP BOOK 00022DB4 / DESC: Palace 교정을 보존한다는 이유로 책 전체의 이전 번역과 영문 병기가 남았다. 최신 ‘시간의 모래시계’ 등 본편 문장을 사용하면서 황궁 교정만 반영했다.
