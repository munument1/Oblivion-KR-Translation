- 전체 Python 회귀·정적 원본 대조·Windows 설치기 실행 검사. 실게임 검증은 사용자 요청에 따라 제외했습니다.
- UOP KR1.12, USIP KR1.9, UODP KR1.10 ZIP은 v1.1.9 배포본을 변경 없이 사용합니다. 상세 내역: [v1.2.0 릴리즈 노트](../release_notes_v1.2.0.md).

### Added
